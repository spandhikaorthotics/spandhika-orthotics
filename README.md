## About

**Spandhika Orthotics Private Limited** is a MedTech startup from Himachal Pradesh, India, building the next generation of intelligent orthotic insoles. Our flagship product — **SAARTHI** — is embedded with a 32-channel pressure sensor array that maps foot pressure in real time, analyzes gait patterns, and delivers personalized clinical insights.

We are bridging the gap between traditional orthotic care and data-driven medicine — making precise foot health accessible, affordable, and continuous.

<br />

## SAARTHI — The Product

> *The world's most advanced smart insole system. SAARTHI doesn't just cushion your step — it understands it.*

| Specification | Detail |
|---|---|
| Pressure Sensor Array | 32 zones · 25 Hz sampling rate |
| Sensing Material | PET Piezoresistive Layer |
| Gait Variables Tracked | 24 parameters |
| Balance Accuracy | 94% symmetry score |
| Data Output | 1M+ data points per day |
| Connectivity | Mobile app (real-time analytics + remote doctor monitoring) |
| Compatibility | Fits inside standard footwear |

**Key capabilities:**
- 🦶 **Pressure Mapping** — High-density sensor array captures dynamic load distribution across the entire footprint
- 📊 **Real-Time Gait Analysis** — Monitors pronation, supination, cadence, and strike patterns instantly
- 🔔 **Preventive Insights** — Predictive algorithms alert users before strain becomes pain
- 🏥 **Remote Monitoring** — Enables doctors to track patient progress without clinic visits
